Static site (plain HTML/CSS, no build step) for Alpha-Gal Wise by WILLIAMS TECHNOLOGIES LLC.
GitHub Pages: serve from the repo root; `CNAME` sets the custom domain alphagalwise.com. alphagalwise.app should redirect at the DNS/registrar level.
Privacy, Terms, and Health Data Privacy pages carry Rev F legal text (effective Nov 4, 2026), approved by Erik and published in commit 7b9cc79. Source fragments: /workspace/legal/RevF_release/. Lettered revisions (Rev A–Z) are pre-release; numbering starts at Rev 1 once released.
